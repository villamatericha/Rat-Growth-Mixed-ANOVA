**Rat Growth Mixed-Design Repeated Measures ANOVA**

**Project Overview**

This project investigates the effects of different treatments on rat growth over five measurement periods using a mixed-design repeated measures analysis of variance (ANOVA). The analysis uses the rats dataset from the nlmm R package.

**Research Objectives**

Examine changes in rat growth across five measurement periods.
Compare rat growth among the three treatment groups.
Determine whether treatment effects on rat growth vary over time.
Assess the assumptions of mixed-design repeated measures ANOVA.
Interpret the statistical results using appropriate post hoc tests.

**Repository Contents**

README.md – Project overview and reproduction instructions.
Rat_Growth_Mixed_ANOVA.R – R script containing the statistical analysis.
Rat_Growth_Mixed_ANOVA.Rmd – R Markdown source file.
Rat_Growth_Mixed_ANOVA.html – Rendered statistical report.
